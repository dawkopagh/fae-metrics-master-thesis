\chapter{Methodology}
\label{ch:methodology}

This chapter presents the evaluation framework developed in this thesis.
Section~\ref{sec:eval-setup} defines the evaluation objective and the unit of
analysis. Sections~\ref{sec:dataset}--\ref{sec:fae-methods} describe the
dataset, predictive models, and feature attribution methods that constitute
the experimental infrastructure. Section~\ref{sec:metrics} specifies the

Sections~\ref{sec:normalization}--\ref{sec:aggregation} detail the score

Section~\ref{sec:celePracy}). Finally, Section~\ref{sec:pipeline} describes
the end-to-end evaluation pipeline and its software implementation.

\section{Evaluation Setup}
\label{sec:eval-setup}

The objective of this evaluation framework is to rank Feature Attribution
Explanation (FAE) methods by an aggregated effectiveness index
$E(\Phi)$ that summarizes performance across six metric categories:
Faithfulness, Robustness, Localization, Complexity, Randomization, and
Axiomatic.

The atomic unit of evaluation is a \emph{per-(model, image, FAE method)
attribution triple}. For a classifier $f$, an input image $x$, and an
explanation method $\Phi$, the triple $(f, x, \Phi)$ yields an attribution
map $\Phi(f, x) \in \mathbb{R}^{C \times H \times W}$, where $C$, $H$, $W$
denote the channel, height, and width dimensions of the input.

For each triple, the \textbf{target class} used for attribution is the
model's top-1 prediction $\hat{y} = \operatorname{argmax}_c f(x)_c$, not
the ground-truth label. This choice is deliberate: evaluation metrics assess
explanation fidelity to \emph{the model's decision}, not to a human-supplied
label. An explanation that faithfully reflects the features driving the
model's prediction is informative regardless of whether that prediction is
correct \cite{hedstrom2023quantus}.

\section{Dataset}
\label{sec:dataset}

The experiments use the ISIC 2017 Challenge dataset (Task~1 -- Lesion
Segmentation), publicly available under a CC-BY-NC license from
\texttt{challenge.isic-archive.com}. The dataset comprises dermoscopic
images distributed across three diagnostic categories: melanoma, nevus, and
seborrheic keratosis.

\begin{itemize}
    \item \textbf{Split sizes:} 2{,}000 training images, 150 validation
    images, 600 test images.
    \item \textbf{Segmentation masks:} Each image is accompanied by an
    expert-annotated binary mask delineating the lesion boundary. These masks
    enable the computation of Localization metrics (Pointing Game, Relevance
    Mass Accuracy) without additional labeling effort -- a key advantage over
    datasets that provide only image-level labels.
    \item \textbf{Preprocessing:} All images are resized to $224 \times 224$
    pixels and normalized using ImageNet channel-wise mean and standard
    deviation ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224,
    0.225]$).
\end{itemize}

The vertical-slice validation (Section~\ref{sec:pipeline}) uses a fixed
subset of 12 images drawn from the test split to verify the end-to-end
plumbing at low computational cost; the full experiment scales the
identical pipeline to all 600 test images. The split sizes above
(2{,}000~/~150~/~600) are those of the official ISIC 2017 Task~1 release
and are held fixed for all experiments to preserve comparability with the
challenge protocol.

\section{Predictive Models}
\label{sec:models}

Two convolutional neural network architectures serve as the predictors whose
decisions are explained. They are not a contribution of this thesis; they
exist solely to produce the attributions that the evaluation framework then
scores.

\subsection{ResNet-18}

ResNet-18 is a residual network with 18 layers organized in four residual
blocks with skip connections \cite{he2016resnet}. The final
fully connected layer is replaced with $\text{Linear}(512, 3)$ to match the
three-class ISIC 2017 classification task.

\subsection{SqueezeNet 1.1}

SqueezeNet 1.1 is a compact architecture that achieves AlexNet-level accuracy
with $\sim$50$\times$ fewer parameters, using Fire modules that combine
$1 \times 1$ squeeze convolutions with mixed $1 \times 1$ and $3 \times 3$
expand convolutions \cite{iandola2016squeeze}. The final classifier layer is replaced with
$\text{Conv2d}(512, 3, 1, 1)$ for three-class output.

\subsection{Training Protocol}

Both models are trained with the following configuration:
\begin{itemize}
    \item \textbf{Epochs:} 25
    \item \textbf{Optimizer:} SGD with momentum ($\text{lr} = 0.001$,
    $\text{momentum} = 0.9$)
    \item \textbf{Scheduler:} StepLR (step size 7, $\gamma = 0.1$)
    \item \textbf{Loss:} Class-weighted CrossEntropyLoss to address class
    imbalance in the ISIC 2017 dataset
    \item \textbf{Random seed:} 42 (set for \texttt{torch}, \texttt{numpy},
    and \texttt{random})
\end{itemize}

Best validation accuracies: ResNet-18 achieves 75.3\%, SqueezeNet achieves
74.0\%; corrected for the class imbalance these are $68.9\%$ and $74.7\%$
balanced accuracy, and the corresponding values on the held-out 600-image
test split are $68.3\%$ and $63.7\%$ (Table~\ref{tab:model-summary}).
Trained weights are saved to disk with SHA-256 checksums documented
in \texttt{weights/README.md}.

\section{Feature Attribution Methods}
\label{sec:fae-methods}

Seven attribution methods are evaluated, spanning gradient-based (white-box)
and perturbation-based (black-box) families. All methods are implemented
using the Captum library, ensuring consistent interfaces and reproducible
gradient computation.

\subsection{Gradient-based Methods}

\subsubsection{Saliency (Vanilla Gradient)}
Computes the absolute gradient of the class score with respect to the input
image (Chapter~\ref{ch:sota}). Computationally efficient but prone to noisy,
non-class-discriminative maps due to shattered gradients.

\subsubsection{Integrated Gradients}
Accumulates gradients along a linear path from a black baseline ($x' = 0$)
to the actual input $x$ using $n\_\text{steps} = 50$ interpolation points
\cite{sundararajan2017axiomatic}. Satisfies the Completeness axiom by
construction.

\subsubsection{Grad-CAM}
Gradient-weighted Class Activation Mapping applied to the last convolutional
layer of the network \cite{selvaraju2017grad}. Produces a coarse
localization map at the resolution of the final feature map, which is then
upsampled to input resolution via bilinear interpolation.

\subsubsection{Guided Backpropagation}
Propagates gradients through only the positive activations at each ReLU
layer, producing sharper maps than vanilla gradients but at the risk of
acting as an edge detector independent of model parameters
\cite{springenberg2015}.

\subsubsection{DeepLift}
Computes attribution by comparing each neuron's activation to a reference
activation produced by a black baseline input ($x' = 0$). Decomposes the
output difference $f(x) - f(x')$ into individual feature contributions
\cite{shrikumar2017deeplift}. Because the torchvision \texttt{BasicBlock}
(ResNet) and \texttt{Fire} (SqueezeNet) modules reuse a single in-place
ReLU across multiple call sites, the implementation operates on a deep
copy of the model in which shared ReLU modules are replaced by unique
non-in-place instances, as required by the Captum DeepLift backend.

\subsubsection{Layer-wise Relevance Propagation (LRP)}
Redistributes the model output backward through the network according to
propagation rules that preserve the total relevance at each layer
\cite{bach2015lrp}. Captum's default LRP rules are applied; both base
classifiers are composed exclusively of layer types supported by these
rules.

\subsection{Perturbation-based Methods}

\subsubsection{Occlusion}
A sliding window of size $(3, 15, 15)$ with stride $(3, 8, 8)$ is passed
over the input, replacing occluded regions with a black baseline ($x' = 0$).
The change in model output for each window position yields a perturbation
sensitivity map \cite{zeiler2014}. Occlusion is the sole perturbation-based
method retained in the final evaluation set.

\subsection{Excluded Candidates}
\label{subsec:excluded-fae}

LIME and KernelSHAP were initially considered as additional perturbation-based
(black-box) methods, alongside Occlusion. They were excluded from the final
evaluation set after compatibility testing on the vertical slice. The
Robustness metrics (Max-Sensitivity and Avg-Sensitivity) and the
Randomization metrics re-invoke the attribution method on perturbed inputs or
randomized models through a Quantus \texttt{explain\_func} callback; the
sampling-based LIME and KernelSHAP estimators are both prohibitively expensive
to re-run for every perturbation sample and produce attribution maps whose
stochastic surrogate fitting makes the resulting sensitivity scores unstable
and difficult to interpret. Occlusion provides a deterministic, Captum-native
perturbation baseline that integrates cleanly with these inner re-computations,
so it alone represents the perturbation family. The final evaluation set is
therefore the seven methods above: six gradient/back-propagation methods
(Saliency, Integrated Gradients, Grad-CAM, Guided Backpropagation, DeepLift,
and LRP) and one perturbation method (Occlusion).

\subsection{Attribution Caching}
\label{subsec:caching}

Attributions are cached to disk, keyed by a tuple of (model architecture,
FAE method, image identifier, target class, hyperparameters hash). This
avoids redundant recomputation when the same attribution is needed by
multiple metrics or across repeated pipeline runs.

The cache is \textbf{bypassed} for inner re-computations performed by
robustness and randomization metrics -- specifically Max-Sensitivity,
Avg-Sensitivity, and MPRT -- because these metrics intentionally perturb
inputs or model weights and therefore produce legitimately different
attributions on each invocation. Caching such perturbed attributions would
violate the metric's operational semantics.

\noindent
The schema retains all twelve metric slots for every attribution triple so
that the result tables have a stable shape, but two of them are excluded
from computation as implementation-driven decisions and recorded as NaN
(subsequently dropped from aggregation rather than imputed):

\begin{itemize}
    \item[$\dagger$] \textbf{ModelParameterRandomisation} is disabled on ISIC
    2017. Under Quantus~0.6.0 its implementation raises an
    \texttt{AssertionError} on every (model, image) sample in this dataset and
    additionally emits a per-call deprecation notice, so it contributes only
    NaN while flooding the log and wasting compute. The exclusion is
    consistent with the literature: the metric's own authors have since
    documented methodological flaws in the original MPRT formulation and
    proposed repaired variants (Smooth-MPRT and Efficient-MPRT)
    \citep{hedstrom2024sanity}. The Randomization category
    remains represented by RandomLogit, which exercises the same sanity-check
    principle (an explanation should change when the target logit is replaced),
    so the category is not lost.
    \item[$\ddagger$] \textbf{NonSensitivity} is excluded by default. A Quantus
    shape bug forces \texttt{features\_in\_step}~=~1, turning the metric into one
    forward pass per feature; at $224 \times 224 \times 3$ this is roughly
    $150{,}000$ passes per image. Even with the input and attribution
    downsampled to $56 \times 56$ (about $9{,}000$ passes, $\sim$34\,s per
    image) the cost is prohibitive at the scale of the full experiment. It can
    be enabled through an \texttt{include\_non\_sensitivity} flag for targeted
    runs.
\end{itemize}

\noindent
With these two exclusions, ten metrics are computed per attribution triple
in the default ISIC~2017 configuration (FaithfulnessCorrelation, PixelFlipping,
MaxSensitivity, AvgSensitivity, RelevanceMassAccuracy, PointingGame,
Sparseness, Complexity, RandomLogit, and Completeness, with Completeness
itself defined only for the three completeness-claiming methods). All six
Quantus categories remain covered.

\paragraph{Faithfulness.}
FaithfulnessCorrelation and PixelFlipping both quantify how well the
attribution map identifies features that the model relies on for its
prediction. FaithfulnessCorrelation uses random subset masking with 100
runs to estimate the Pearson correlation between attribution magnitude and
output change; higher is better. PixelFlipping removes features in
descending order of attributed importance and reports the area under the
degradation curve of model outputs; a faithful attribution collapses the
prediction early, so \emph{lower} is better
\cite{hedstrom2023quantus}.

\paragraph{Robustness.}
MaxSensitivity and AvgSensitivity evaluate explanation stability under
small uniform-noise perturbations of the input (the Quantus implementation
draws uniform noise with magnitude bounded by \texttt{lower\_bound}). Both
use 10 perturbation samples
with a perturbation magnitude lower bound of 0.2. MaxSensitivity reports
the worst-case sensitivity, while AvgSensitivity reports the average.
Lower is better for both \cite{hedstrom2023quantus}.

\paragraph{Localization.}
RelevanceMassAccuracy and PointingGame evaluate spatial agreement between
the attribution map and the expert-annotated lesion mask. Both are
higher-is-better and require segmentation masks at inference time
\cite{hedstrom2023quantus}.

\paragraph{Complexity.}
Sparseness (Gini-like, higher-is-better) and Complexity (Shannon entropy,
lower-is-better) assess the conciseness of the attribution distribution.
These metrics are model-agnostic and computed directly from the attribution
map \cite{hedstrom2023quantus}.

\paragraph{Randomization.}
ModelParameterRandomisation (MPRT) progressively randomizes model weights
top-down and measures correlation decay. RandomLogit replaces the target
class and measures explanation change. Lower correlation is better for both,
indicating that the explanation genuinely depends on learned parameters and
the specified target class \cite{hedstrom2023quantus}. As noted above, MPRT
is disabled on ISIC~2017 because of a Quantus~0.6.0 incompatibility, leaving
RandomLogit as the operative Randomization metric.

\paragraph{Axiomatic.}
Completeness tests the completeness axiom
($\sum_i E_i = \Delta f$) as a strict floating-point equality, returning a
Boolean per sample (satisfied~$=1$, higher is better) rather than the
magnitude of the deviation. It returns NaN for methods outside
\{Integrated Gradients, DeepLift, LRP\}; these NaN values are excluded
from aggregation rather than imputed. NonSensitivity measures attribution
mass on provably non-contributory features. Due to its $O(d)$ forward-pass
cost, the input is downsampled to $56 \times 56$, and the metric is
excluded from all runs by default \cite{hedstrom2023quantus}.

\subsection{Metric Redundancy Pruning}
\label{subsec:redundancy-pruning}

The reduced metric set $M^{*}$ (Contribution~1) is derived per model in
three steps.

\emph{Variance pre-screen.} Within each model group, a metric is removed
before correlation analysis if its non-NaN fraction falls below $0.20$ or
the standard deviation of its scores falls below $10^{-6}$ (a constant
metric carries no ranking signal; a mostly-NaN metric yields unstable
correlation estimates).

\emph{Correlation matrix.} For the surviving metrics, the Spearman
rank-correlation matrix is computed on the wide table whose observations
are (image, FAE-method) pairs -- i.e.\ correlations are pooled across
attribution methods as well as images, so ``redundant'' means that two
metrics order the full population of explanations alike, not merely that
they agree for one method. Spearman is used rather than Pearson because
the raw metric scales are heterogeneous and partly unbounded.

\emph{Greedy pruning (Decision~D4).} While any pair of surviving metrics
has $|\rho| > 0.85$, the member of the pair with the \emph{higher} mean
absolute correlation to the rest of the surviving set is dropped (the
retained member is the one carrying more independent signal); the
procedure iterates until no pair exceeds the threshold. The threshold
$0.85$ follows the convention of treating $|\rho|$ above ${\sim}0.85$ as
operational collinearity; Chapter~\ref{ch:discussion} discusses its
sensitivity. The procedure is run per model, and the reported $M^{*}$ is
the cross-model intersection.

\section{Score Normalization}
\label{sec:normalization}

The twelve metrics operate on heterogeneous scales (e.g.,
FaithfulnessCorrelation $\in [-1, 1]$, MaxSensitivity $\in [0, \infty)$,
Sparseness $\in [0, 1]$) and have heterogeneous directionalities (some
higher-is-better, some lower-is-better). Aggregation requires
rectification and rescaling.

\subsection{Direction Rectification}

Each metric $k$ is assigned a direction sign $s_k \in \{+1, -1\}$, where
$s_k = +1$ for higher-is-better metrics and $s_k = -1$ for
lower-is-better metrics. The rectified score is:
\begin{equation}
    \hat{M}_k(\Phi) = s_k \cdot M_k(\Phi),
\end{equation}
so that a higher rectified score always indicates better performance.

\subsection{Second Moment Scaling}

The default scale-rectifying transformation is Second Moment Scaling,
adopted from the NormEnsembleXAI framework (Decision~D1)
\cite{hryniewska2024normensemblexai}:
\begin{equation}
    \tilde{M}_k(\Phi) = \frac{\hat{M}_k(\Phi)}{\sqrt{\mathbb{E}\bigl[\hat{M}_k^2\bigr]}},
\end{equation}
where the expectation is computed within each (model, metric) group
independently. This transformation does not require knowledge of global
extremes, avoids min--max normalization's total dependence on the two most
extreme values (though its squared term remains sensitive to heavy tails,
as Chapter~\ref{ch:discussion} documents for the raw score
distributions), and
preserves the sign structure of the rectified scores.

Two alternative normalizations are implemented for ablation studies:
\begin{itemize}
    \item \textbf{$z$-score normalization:}
    $\psi_k(x) = (x - \mu_k) / \sigma_k$, centering on the group mean with
    unit variance.
    \item \textbf{Min--max normalization:}
    $\psi_k(x) = (x - \min_k) / (\max_k - \min_k)$, mapping scores to
    $[0, 1]$. Sensitive to outliers and requires knowing the global extremes.
\end{itemize}

\section{Score Aggregation}
\label{sec:aggregation}

Once normalized, the per-metric scores are aggregated into a single
effectiveness index $E(\Phi)$ per (model, image, FAE method). Three
aggregation operators are implemented (Decision~D2):

\begin{enumerate}
    \item \textbf{Weighted mean (default, recommended):}
    \begin{equation}
        E(\Phi) = \sum_{k=1}^{K} w_k \, \tilde{M}_k(\Phi),
    \end{equation}
    where $w_k \geq 0$ and $\sum_k w_k = 1$.

    \item \textbf{Minimum (conservative):}
    \begin{equation}
        E(\Phi) = \min_{k=1,\dots,K} \tilde{M}_k(\Phi).
    \end{equation}
    Evaluates a method by its worst dimension. In safety-critical domains, a
    method that is faithful but unstable is ineligible regardless of how high
    its faithfulness score is.

    \item \textbf{Geometric mean:}
    \begin{equation}
        E(\Phi) = \exp\!\left(\sum_{k=1}^{K} w_k \ln\bigl(\tilde{M}'_k(\Phi) + \varepsilon\bigr)\right),
    \end{equation}
    where $\varepsilon > 0$ is a small constant to avoid $\ln(0)$ and
    $\tilde{M}'_k = \tilde{M}_k - \min_j \tilde{M}_j(\cdot)$ shifts the
    rectified scores to non-negative support first (rectified scores of
    lower-is-better metrics are routinely negative, so the logarithm is
    otherwise undefined). Penalizes
    methods with a near-zero score on any single axis.
\end{enumerate}

The default weight vector uses uniform weights: $w_k = 1/K$ for $K$
retained metrics after the redundancy and meta-evaluation filtering whose
procedure is specified in Chapter~\ref{ch:experiments} (the underlying
redundancy and meta-evaluation concepts are reviewed in
Chapter~\ref{ch:sota}).

\subsection{Autoweighted Extension}
\label{sec:weighting}

The Autoweighted mechanism, adopted from \citet{hryniewska2024normensemblexai},
derives a weight for each metric from the dispersion of its scores across the
test set: metrics whose scores are internally consistent are trusted more than
metrics whose scores are noisy. Concretely, for each (model) group and each
metric $k$, let $\mathrm{cv}_k = \mathrm{std}(M_k) / |\mathrm{mean}(M_k)|$ be
the coefficient of variation of metric $k$'s raw scores over the test images.
The agreement weight is the inverse coefficient of variation, normalised to a
convex combination:
\begin{equation}
    a_k = \frac{1}{\mathrm{cv}_k + \varepsilon},
    \qquad
    w_k^{\mathrm{AW}} = \frac{a_k}{\sum_{j \in M^{*}} a_j},
    \label{eq:autoweighted}
\end{equation}
where $\varepsilon = 10^{-8}$ provides numerical stability and all statistics
are NaN-aware. A metric with a low coefficient of variation (stable across
images relative to its mean) receives a high weight; a noisy metric receives a
small one. Metrics whose scores are all-NaN in a group receive $a_k = 0$, and
the remaining weights renormalise so that $\sum_k w_k^{\mathrm{AW}} = 1$.
The statistics are pooled across all FAE methods and test images within a
model group. The
coefficient of variation is scale-invariant, so Autoweighted yields the same
result whether computed on raw or Second-Moment-scaled scores (this
invariance does not extend to the $z$-score alternative, whose centring
removes the mean the CV depends on).

Two structural caveats of inverse-CV weighting are acknowledged as
modelling assumptions rather than hidden. First, the CV is
\emph{location-sensitive}: for a metric whose scores straddle zero --
FaithfulnessCorrelation, with range $[-1, 1]$, is the case in point --
$|\mathrm{mean}(M_k)|$ can be small for reasons unrelated to noise, which
inflates the CV and suppresses the weight as an artefact of where the
scale's zero sits. Second, consistency is not discriminative power: a
degenerate metric returning a near-constant score would receive maximal
weight while carrying no ranking signal (the variance pre-screen of
Section~\ref{subsec:redundancy-pruning} removes the limiting case, but the
gradient of the pathology remains). Both caveats motivate testing, rather
than assuming, whether the reliability discount of the next subsection
changes the induced ranking.

\subsection{MetaQuantus-discounted Weighting (Contribution~2)}
\label{subsec:mq-discount}

The reliability-discounted weighting scheme of this thesis (Decision~D3)
combines two signals
that are conventionally treated in isolation: how internally consistent a
metric's scores are (the Autoweighted signal above), and how reliable that
metric is when probed by meta-evaluation. The derivation proceeds in three
steps.

\paragraph{Step 1 -- Autoweighted agreement weight.}
For each retained metric $k \in M^{*}$, the Autoweighted coefficient
$w_k^{\mathrm{AW}}$ is computed per Equation~\eqref{eq:autoweighted}.

\paragraph{Step 2 -- Reliability discount.}
Each metric is assigned a reliability coefficient $\lambda_k \in [0, 1]$
obtained from the meta-evaluation stage
(Section~\ref{subsec:meta-evaluation} of Chapter~\ref{ch:sota}). MetaQuantus
produces two scores per metric: a Noise Resilience score $\mathrm{NR}_k$ and
an Adversarial Reactivity score $\mathrm{AR}_k$. These are this thesis's
MetaQuantus-\emph{inspired} estimators of the two reliability properties,
not the published IAC/IEC consistency estimators:
$\mathrm{NR}_k = 1/(1 + \mathrm{CV})$, where CV is the coefficient of
variation, across five noise seeds, of the metric's score
\emph{averaged over the 64 sampled images} -- an estimand whose
consequences are analysed in Section~\ref{sec:exp-meta}, since averaging
before taking the CV compresses the very dispersion NR is meant to
detect -- and
$\mathrm{AR}_k = |\rho_S|$, the absolute Spearman correlation between the
explanation-degradation levels and the mean metric score at each level
(five levels; ten for the extended-AR completion).
Both are computed on the same fixed, seed-determined 64-image random sample
of the test split per
(model, FAE) cell, so every metric's $\lambda_k$ rests on a single sample.
The combined
reliability is their equal-weight mean,
\begin{equation}
    \lambda_k \;=\; \tfrac{1}{2}\bigl(\mathrm{NR}_k + \mathrm{AR}_k\bigr),
    \label{eq:lambda}
\end{equation}
reported per (model, FAE, metric) in
\texttt{results/meta\_evaluation\_reliability.csv} and averaged over the
(model, FAE) cells in which the metric is defined. For the two
explanation-recomputing metrics, the original NR-stage measurements failed
silently and were discarded as artifacts; their NR was re-measured with a
repaired estimator on the same sample
(Section~\ref{sec:exp-meta}), so both legs of every $M^{*}$ metric's
$\lambda_k$ are measured. Because $|\rho_S|$ over
five levels has a granularity of ${\sim}0.1$ (finer at the ten levels used
for the extended-AR completion) and is direction-agnostic,
reliability values are reported to two decimals and the direction of each
cell's reactivity is audited in Chapter~\ref{ch:experiments}.
One further limitation of Equation~\eqref{eq:lambda} follows from the two
AR protocols coexisting in the same average: a five-level $|\rho_S|$ and a
ten-level $|\rho_S|$ have different null expectations ($0.42$ against
$0.27$, Section~\ref{sec:exp-meta}), so raw AR values from the two
protocols are not on a common scale, yet
$\lambda_k$ combines them additively with NR as though they were.
Chapter~\ref{ch:experiments} reports each metric's AR against \emph{its
own} null rather than against the others', and a null-referenced
(floor-subtracted) AR is recorded as future work; the values as computed
are best read as protocol-conditional reliability indices, not as
calibrated probabilities of reliability.
Figure~\ref{fig:ar-schematic} illustrates the estimator on two measured
cells, including one whose reactivity runs opposite to the expected
direction -- exactly the case the audit exists to expose.

    \label{fig:ar-schematic}
\end{figure}

The AR test requires one protocol extension. MetaQuantus degrades the
explanation by zeroing a growing fraction of the attribution array, but the
metrics that re-compute attributions internally through
\texttt{explain\_func} (the sensitivity metrics and RandomLogit) ignore that
array, so the degradation would never reach them and their level scores would
be constant. For those metrics the degradation is therefore additionally
injected into the explanation function itself: at degradation fraction $f$,
each invocation of the wrapped explainer zeroes a fresh, independently drawn
random fraction $f$ of its output, so the metric's internal re-explanations
lose signal at the same rate as the explicit attribution. The degradation is
capped at $f = 0.9$ because a fully zeroed attribution is rejected by the
metric implementations. With this extension, every computable metric carries
a measured combined reliability.

Where \texttt{combined\_reliability} is undefined for a metric that
nonetheless enters an aggregation -- a configuration safeguard: in the
reported run every $M^{*}$ metric carries a measured reliability, so the
hierarchy is not exercised -- $\lambda_k$ is resolved by an
explicit fallback hierarchy: (i)~the Noise-Resilience-only score, where NR
alone is available;
(ii)~the mean reliability of the other valid metrics in the same
Quantus category; (iii)~the global mean reliability across the group; and, as
a last resort, (iv)~no discount ($\lambda_k = 1$). This fallback never zeroes a
metric out, which would silently drop it from the ensemble.

\paragraph{Step 3 -- Discounted normalisation.}
The Autoweighted coefficient is attenuated by the reliability factor and
renormalised to a convex combination:
\begin{equation}
    w_k = \frac{w_k^{\mathrm{AW}} \, \lambda_k}
               {\sum_{j \in M^{*}} w_j^{\mathrm{AW}} \, \lambda_j},
    \qquad w_k \geq 0, \quad \sum_{k \in M^{*}} w_k = 1.
    \label{eq:mq-discount}
\end{equation}
Equation~\eqref{eq:mq-discount} is the MetaQuantus-discounted Autoweighted
operator. It reduces to the plain Autoweighted scheme of
\citet{hryniewska2024normensemblexai} when every metric is perfectly reliable
($\lambda_k \equiv 1$), and it attenuates $w_k$ toward zero for a metric
that is either
internally noisy (small $w_k^{\mathrm{AW}}$) or unreliable under
meta-evaluation (small
$\lambda_k$); being multiplicative, however, it can only rescale the
Autoweighted allocation, so a metric with a large agreement weight retains
substantial influence unless its $\lambda_k$ is itself small.
The three weighting schemes -- uniform, Autoweighted, and
MQ-discounted -- are reported side by side in Chapter~\ref{ch:experiments} so
that their effect on the final method ranking can be assessed directly.

\section{The Evaluation Pipeline}
\label{sec:pipeline}

The end-to-end evaluation pipeline integrates all components described in
this chapter into a single reproducible data flow:

\begin{enumerate}
    \item \textbf{Input:} ISIC 2017 test images and associated binary lesion
    masks.
    \item \textbf{Model inference:} For each image $x$, the classifier $f$
    produces a prediction $\hat{y} = \operatorname{argmax}_c f(x)_c$, which
    serves as the target class for attribution.
    \item \textbf{Attribution generation:} Each FAE method $\Phi$ computes an
    attribution map $\Phi(f, x) \in \mathbb{R}^{3 \times 224 \times 224}$.
    Results are cached to disk (Section~\ref{subsec:caching}).
    \item \textbf{Metric computation:} The twelve metrics from
    Table~\ref{tab:metrics} are applied to each attribution map, producing a
    vector of raw scores per (model, image, FAE method).
    \item \textbf{Normalization:} Direction rectification and Second Moment
    Scaling (Section~\ref{sec:normalization}) transform raw scores into a
    comparable scale.
    \item \textbf{Aggregation:} The normalized scores are combined into a
    single effectiveness index $E(\Phi)$ via the chosen aggregation operator
    (Section~\ref{sec:aggregation}).
    \item \textbf{Ranking:} FAE methods are ranked per-model by their mean
    $E(\Phi)$ across test images.
\end{enumerate}

Figure~\ref{fig:pipeline} summarises this flow. The diagram makes explicit
the two contribution boundaries: the meta-evaluation block
(redundancy~+~meta-validation) yields the reduced metric set $M^{*}$
(Contribution~1), and the aggregation block (normalisation, weighting,
combination) yields the effectiveness index $E(\Phi)$ (Contribution~2),
which the statistical-comparison stage (Contributions~3--4) consumes.

\subsection{Implementation}

The pipeline entry point is \texttt{experiments/vertical\_slice.py}. The
output is a long-format CSV file with columns \texttt{model},
\texttt{image\_id}, \texttt{fae\_method}, \texttt{metric}, and \texttt{score}.
The schema retains one row per (model, image, FAE method, metric~slot),
including the slots recorded as NaN (the excluded metrics and Completeness on
non-completeness methods), so that the table shape is independent of which
metrics happen to be defined for a given triple. A third, unintended source
of NaN survives in the full run: 70 of the 100{,}800 score slots -- all in
the (ResNet-18, Grad-CAM) cell, split across avg\_sensitivity~(17),
max\_sensitivity~(18), and random\_logit~(35), i.e.\ up to $5.8\%$ of that
metric's scores for that cell -- record a failed metric call rather than a
designed exclusion. All three are explanation-recomputing metrics, and the
failures are confined to the one FAE method whose attributions are
computed at reduced spatial resolution. They are dropped pairwise by the
NaN-aware aggregation of Section~\ref{sec:normalization} rather than
imputed, so they cannot propagate into the index, but they do mean that
cell's statistics rest on marginally fewer images than the rest. For the 12-image vertical
slice this is $2 \times 7 \times 12 \times 12 = 2{,}016$ rows (2~models
$\times$ 7~FAE methods $\times$ 12~images $\times$ 12~metric slots); scaling
the identical schema to all 600 test images yields
$2 \times 7 \times 600 \times 12 = 100{,}800$ rows.

The software architecture follows the modular layout described in
Section~\ref{sec:celePracy}:
\begin{itemize}
    \item \texttt{src/data/} -- ISIC 2017 dataset class and download script.
    \item \texttt{src/models/} -- Classifier definitions and training loop.
    \item \texttt{src/attributions/} -- Attribution generation, disk cache,
    NormEnsembleXAI wrapper.
    \item \texttt{src/metrics/} -- Quantus wrapper, custom metrics,
    redundancy analysis.
    \item \texttt{src/meta\_evaluation/} -- MetaQuantus wrapper and metric
    selection.
    \item \texttt{src/aggregation/} -- Normalization, aggregation operators,
    weighting schemes.
    \item \texttt{src/comparison/} -- Wilcoxon, Friedman, and Nemenyi
    statistical tests.
    \item \texttt{src/pipeline.py} -- End-to-end orchestrator.
\end{itemize}

Reproducibility is anchored in three committed artifact classes rather
than declarative configuration files: the Colab notebooks that run the GPU
stages (seeds, metric hyperparameters, and the Quantus version fixed in
code), the raw result CSVs they produce, and the deterministic
post-processing scripts under \texttt{experiments/} that regenerate every
reported table from those CSVs; the exact package environment is recorded
in \texttt{requirements-lock.txt}.

\paragraph{Design decision register.} For ease of reference, the design
decisions cited as D1--D6 throughout Chapters~\ref{ch:experiments}
and~\ref{ch:discussion} are collected here:

\begin{description}
    \item[D1] Second Moment Scaling as the score normalisation, adopted from
    NormEnsembleXAI (Section~\ref{sec:normalization}).
    \item[D2] Three aggregation operators -- weighted mean, minimum, and
    geometric mean -- with the weighted mean as the default
    (Section~\ref{sec:aggregation}).
    \item[D3] The MetaQuantus-discounted Autoweighted weighting as the novel
    weighting scheme under test (Section~\ref{subsec:mq-discount}).
    \item[D4] Greedy redundancy pruning at $|\rho| > 0.85$ over the pooled
    (cross-category) correlation matrix, with variance pre-screening
    (Section~\ref{subsec:redundancy-pruning}); a strictly within-category
    policy is the considered alternative.
    \item[D5] Friedman $+$ Nemenyi for the omnibus method comparison and
    Wilcoxon signed-rank for the paired individual-vs-ensemble comparison
    (Section~\ref{sec:pipeline}).
    \item[D6] NormEnsembleXAI Mean aggregation with Second Moment
    normalisation as the attribution-ensembling configuration
    (Section~\ref{sec:fae-methods}).
\end{description}
